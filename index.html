Cloudflare Worker (Canlı Bilgi & .m3u8)

Doğrudan

Embed modu her zaman çalışır. Kendi ücretsiz Cloudflare Worker'ını eklersen canlı izleyici sayıları ve HLS .m3u8 akışları (kalite seçimi için) otomatik çekilir.

CORS + M3U8 Worker Kodu (15 satır): 
export default {
  async fetch(req) {
    const cors = { "Access-Control-Allow-Origin": "*", "Access-Control-Allow-Methods": "GET,OPTIONS" };
    if (req.method === "OPTIONS") return new Response(null, { headers: cors });
    const target = new URL(req.url).searchParams.get("url");
    if (!target || !/^https:\/\/([a-z0-9-]+\.)?(kick\.com|live-video\.net)\//i.test(target)) {
      return new Response("Geçersiz URL", { status: 400, headers: cors });
    }
    const r = await fetch(target, { headers: { "User-Agent": "Mozilla/5.0" } });
    const ct = r.headers.get("Content-Type") || "application/octet-stream";
    return new Response(r.body, {
      status: r.status,
      headers: { ...cors, "Content-Type": ct }
    });
  }
};
